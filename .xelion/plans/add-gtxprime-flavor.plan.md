# Add new flavor "GTX Prime" (child of `vantage`)

## Goal
Add a new brand/flavor **GTX Prime** to the white-label app as a `child` of the
`vantage` parent. It keeps its own colors, title, app id, and assets, but inherits
vantage's screens. For now it points at the Tenax backend URLs (`demo.tenaxcode.com`)
— these will be swapped to GTX Prime's own domain later.

## Approach
This repo uses a **one client = one folder** workflow. The single source of truth is
`assets/brands/<brand>/brand.yaml` + 3 artwork files. Everything else is auto-generated
by `scripts/generate_brand_config.dart` and must NOT be hand-edited:
- `assets/config/brands/brands.yaml` & `brands.json`
- `lib/clients/gtxprime/config.dart` & `launcher_icons.yaml`
- `lib/flavor_config.dart`
- `android/brand_flavors.gradle`
- `.vscode/launch.json`
- `android/app/src/gtxprime/res/values/colors.xml`

Identifiers (confirmed with user):
- brand name (folder/flavor): `gtxprime`
- label: `GTX Prime`
- applicationId / bundleId: `com.gtxprime.app`
- URLs: temporarily reuse Tenax (`demo.tenaxcode.com`) — change later.

## Steps
- [x] Step 1 — Ensure source folder exists: `assets/brands/gtxprime/`.
- [x] Step 2 — Add 3 artwork files (placeholders OK; copy from `assets/brands/vantage/`):
      `assets/brands/gtxprime/icon.png`, `logo.svg`, `splash_logo.svg`.
- [x] Step 3 — Create `assets/brands/gtxprime/brand.yaml` with the content below.
- [x] Step 4 — Run `dart run scripts/generate_brand_config.dart` to regenerate all
      derived config (config.dart, flavor_config.dart, gradle, brands.json/yaml,
      colors.xml, launch.json).
- [x] Step 5 — (iOS) Run `dart run scripts/prepare_flavor.dart gtxprime` to set iOS
      bundle id, app name, icon, splash, and DART_DEFINES.
- [x] Step 6 — Verify generated `lib/clients/gtxprime/config.dart` has correct values
      and that `gtxprime` appears in `lib/flavor_config.dart`,
      `android/brand_flavors.gradle`, and `.vscode/launch.json`.
- [x] Step 7 — Build/run: `./build.sh gtxprime apk release` (Android) or open
      `ios/Runner.xcworkspace` and Run (iOS).

## Risks / Open questions
- **URLs are temporary**: currently point at Tenax's `demo.tenaxcode.com`. Update
  `urls:` in `brand.yaml` and re-run the generator when GTX Prime's real backend is ready.
- **Artwork**: if placeholders are copied from vantage, the app icon/logo/splash will
  look like Vantage until real GTX Prime art replaces the 3 files (then re-run prepare/build).
- **Push notifications**: optionally add `assets/brands/gtxprime/google-services.json`
  (Android) and `GoogleService-Info.plist` (iOS) for Firebase; otherwise push setup is skipped.
- After switching flavors on iOS, may need Xcode → Product → Clean Build Folder (⇧⌘K).
